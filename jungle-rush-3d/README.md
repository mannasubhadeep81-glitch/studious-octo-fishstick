# Jungle Rush 3D

A mobile-first 3D endless-runner prototype built with Godot 4.3. It uses original primitive-based visuals and is inspired by the endless-runner genre, not Temple Run's protected characters, art, or branding.

## Controls
- Swipe left/right: change lanes
- Swipe up: jump
- Swipe down: slide
- Keyboard: arrows or WASD; Space to jump

## Current prototype
- Auto-running character
- Three lanes
- Procedurally generated jungle track and trees
- Obstacles and collectible gold rings
- Increasing speed, distance score, coin count, game-over and restart
- Compatibility renderer for broader mobile support

## Android build
The Android export preset and GitHub Actions workflow are included. The first CI run must succeed before an installable APK can be claimed. This is a prototype using procedural low-poly shapes; polished character models, animation, sound, menus, and device performance testing are later steps.
