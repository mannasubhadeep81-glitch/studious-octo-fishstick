# LUMIRA Racing

A standalone mobile-friendly 2D arcade racing prototype.

## Current build
- Canvas-based 2D rendering
- Parallax city/highway scenery
- Player car + traffic cars
- Nitro boost
- Touch controls and keyboard controls
- Particles, smoke and speed feedback
- Score and local best score
- Responsive landscape/mobile layout
- No external game assets or dependencies required

## Play
Open `racing/index.html` through GitHub Pages or any static web host.
